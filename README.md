# Robot d'Exploration Web (Web Crawler)

Ce projet est un script Python développé sur Android via Termux. Il permet de se connecter à n'importe quel site internet pour en extraire automatiquement tous les liens hypertextes et les sauvegarder dans un fichier texte.

## Fonctionnalités
- Connexion sécurisée via la bibliothèque `requests`
- Analyse structurelle HTML avec `BeautifulSoup4`
- Sauvegarde automatisée des résultats dans `resultats.txt`
